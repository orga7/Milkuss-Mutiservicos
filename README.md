## 🚀 Publicar no GitHub Pages

1. Criar um repositório no GitHub (ex: `milkuss-multiservicos`)
2. Fazer upload dos ficheiros (`index.html`, `README.md`, `.gitignore`) para o repositório
3. Ir em **Settings > Pages**
4. Em **Source**, seleccionar `main` branch e pasta `/ (root)`
5. Clicar em **Save**
6. O site ficará disponível em: `https://<username>.github.io/milkuss-multiservicos/`
